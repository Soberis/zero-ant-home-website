# ZeroAnt 官网设计方案 V4

> 目标：把官网收敛成“品牌可信、结构清楚、选型高效、视觉克制”的工业机器人官网。  
> 关键词只有五个：**大气、美观、简约、实用、协调**。  
> 这份文档只写可执行规则，不写空泛审美词。

## 1. 设计总判断

- **大气**：靠大留白、真实产品图、清晰层级，不靠特效堆场面。
- **美观**：靠比例、节奏、图文关系和统一约束，不靠花哨组件。
- **简约**：每个页面只保留一个主任务，每个 section 只做一件事。
- **实用**：用户能快速理解产品系列、型号差异、扩展机构适配和下一步动作。
- **协调**：首页、产品中心、详情页、支持页使用同一套视觉语言和信息逻辑。

一句话方向：

**像成熟工业科技品牌，不像模板站；像可选型的产品官网，不像只有宣传情绪的展示页。**

## 2. 参考策略

这次产品入口统一收敛成一个 **产品中心**。

### 2.1 主参照与辅参照

- **睿尔曼产品中心**：主参考对象，主要学习系列分组、多型号承载、配件并列、支持链路和目录组织方式。
- **Franka**：辅参考对象，主要学习页面克制感、CTA、详情页的参数表达和配件分层。
- **NEURA**：只参考首页首屏的品牌气质，不再作为产品中心结构参考。

### 2.2 对 ZeroAnt 的映射

- 首页中下段：`Franka 60% + NEURA 40%`
- 产品中心：`睿尔曼 80% + Franka 20%`
- 产品详情页：`Franka 60% + 睿尔曼 40%`

### 2.3 为什么产品中心更该学睿尔曼

- 睿尔曼当前产品中心按系列展开，再落到具体型号和配件，结构上和 ZeroAnt 现在的产品复杂度更接近。  
  来源：[睿尔曼产品中心](https://www.realman-robotics.cn/products)
- Franka 更适合拿来学页面克制和详情页可信度，不适合直接当 ZeroAnt 的产品中心模板。  
  来源：[Franka 官网](https://franka.de/)
- NEURA 更强的是品牌势能，不适合作为产品目录的主结构。  
  来源：[NEURA 官网](https://neura-robotics.com/)

### 2.4 不学什么

- 不学睿尔曼偏拥挤的目录密度。
- 不学 Franka 的单核产品思路。
- 不学 NEURA 的整站生态叙事。

结论很明确：

**ZeroAnt 的产品中心学睿尔曼是对的，但只学信息架构，不学视觉拥挤感。**

## 3. 本轮改造边界

这一轮不做全站推翻，只改最关键的主链路。

### 3.1 本轮主改页面

1. **产品中心**
2. **产品详情页**

### 3.2 首页怎么处理

- 首页首屏 Hero 不作为本轮主要改动对象。
- 首页只收紧 Hero 以下的中下段结构。
- 首页的职责仍然是品牌入口和流量分发，不承担完整选型。

### 3.3 需要联动收敛的公共区块

虽然本轮主改只有 2 类页面，但下面这些公共区块必须一起收敛：

- **NavBar**
  导航命名、当前页高亮、产品入口结构要和新的产品中心一致。
- **Footer**
  产品入口、支持入口、联系入口要和新的产品分层保持一致。
- **Sticky Filter Bar**
  用在产品中心，承担系列筛选。
- **Sticky Anchor Bar**
  用在产品详情页，承担段落导航。
- **通用 CTA**
  `查看详情`、`下载资料`、`联系团队` 三类按钮保持统一。

### 3.4 为什么这样改仍然会协调

协调不是“每一页都大改”，而是以下五件事统一：

- 同一套品牌色和字体
- 同一套 section 间距与栅格
- 同一套 CTA 逻辑
- 同一套标题节奏
- 同一套页面信息顺序

### 3.5 路由与导航口径

- 前台产品入口统一为单一 `/products`。
- 首页产品入口、NavBar、Footer、CTA 文案统一只出现一个“产品中心”。
- 文档层面不再保留任何历史产品路由、历史产品入口或兼容说明。
- 页面、导航、Footer、多语言文案统一只保留“产品中心”这一种产品入口命名。

## 4. 现阶段核心问题

### 4.1 当前问题

- 首页结构基本成立，但产品入口仍然偏分散。
- 旧的产品页偏“平铺卡片”，不适合承载越来越多的系列、型号和扩展机构。
- 产品详情页更像介绍页，不够像选型页。
- 扩展机构缺少明确展示策略，容易和主机产品抢层级。

### 4.2 必须明确的新逻辑

以后产品体系统一按下面 4 层组织：

1. **系列**
2. **型号**
3. **扩展机构**
4. **推荐组合**

不要再把所有东西都当成同一种“产品卡片”。

- 导航、Footer、首页入口一律只显示“产品中心”，不再拆分其他历史产品入口。

- R 系列：`ZA-R3 / ZA-R3X`、`ZA-R3L / ZA-R3M / ZA-R3H`、`ZA-R3M(L)`、`ZA-R3M(R)`、`ZA-R3D6`、`ZA-R3T`

### 5.4 扩展机构展示结构

扩展机构不与主机平权展示，默认作为：

- 产品中心中的“扩展机构专区”
- 产品详情页中的“关联扩展机构”模块

只有满足以下条件，才单独做扩展机构详情页：

- 扩展机构独立销售
- 适配多个系列
- 参数复杂
- 需要独立 SEO

## 7. 视觉系统

### 7.1 颜色

- 主色：ZeroAnt 深蓝
- 背景：白、浅灰
- 辅助色：只允许一个 CTA 强调色
- 状态色：只用于标签、表单、状态提示

### 7.2 字体

- 标题：`Outfit`
- 正文：`Inter`

规则：

- H1 控制在 2 到 3 行
- H2 控制在 1 到 2 行
- 正文一段尽量不超过 3 行
- 参数值要清楚，不写营销话术

### 7.3 栅格与间距

- 主内容宽度保持统一
- Hero 内文字列保持窄栏，图像做主导
- section 间距统一，不允许有的松有的挤

建议节奏：

- Hero 与下一 section：64 到 88
- 普通 section 间距：56 到 72
- 组内元素间距：16 / 24 / 32

### 7.4 图片

- 只用真实产品图、真实案例图、真实场景图
- 不用 fake UI、抽象 3D、无关 stock 图
- 产品图优先干净背景，保证文字可读

### 7.5 卡片

- 默认不用卡片
- 只有这些地方保留卡片：
  - 型号卡片
  - 扩展机构卡片
  - 视频
  - 下载
  - FAQ

### 7.6 动效

全站只保留三类动效：

1. 首屏入场
2. 滚动 reveal
3. hover / accordion 过渡

规则：

- 同一套 easing
- 持续时间短，感觉稳
- `prefers-reduced-motion` 自动降级

### 7.7 主页面协调规则

- 首页中下段、产品中心、产品详情页共用同一套标题节奏、容器宽度和 section 间距。
- NavBar、Footer、Bar 体系都使用统一按钮风格和状态色。
- 页面信息顺序统一为：
  `先说明定位` -> `再说明能力/参数` -> `最后给行动入口`

## 11. 验收标准

### 11.1 品牌层

- 3 秒内看懂 ZeroAnt 做什么
- 首页首屏不靠解释也能建立品牌感
- 全站像一个成熟品牌，不像拼起来的模板

### 11.2 结构层

- 用户能先看系列，再看型号，再看扩展机构
- 3 步内能到产品详情、联系或下载
- 型号差异能直接比较，不需要来回翻页
- 产品中心一眼看出系列结构，不需要反复滚动猜分类
- 导航、首页入口、Footer 都只出现一个“产品中心”

### 11.3 视觉层

- 去掉阴影和装饰后，页面仍然成立
- 全站只保持一套主色、两套字体、统一 spacing
- 图片、文案、动效不会同时抢焦点

### 11.4 业务层

- 产品页不再只是介绍，而能支持初步选型
- 扩展机构不再混乱抢层级
- 支持页能承担转化和答疑

## 12. 一句话执行原则

- 先改信息结构，再改视觉表现
- 先解决选型效率，再谈视觉惊艳
- 任何元素如果不能服务品牌、信息或转化，就删掉
